# Tic Tac Toe Game 🎮

This project is a **Java implementation of Tic Tac Toe** designed to demonstrate key programming concepts and best practices. It was developed as part of coursework to integrate multiple areas of Java development into a single, functional application.

## ✨ Features
- **Game Board:** 3×3 array with initialization and display methods.
- **Enums & OOP:** Player symbols defined with enums; encapsulated Player class with inheritance (ComputerPlayer).
- **Exception Handling:** Custom `InvalidMoveException` with try–catch–finally blocks.
- **Collections:** ArrayList used to store and display all moves played.
- **File I/O & Serialization:** Saves winners to `score.txt` and serializes Player objects.
- **Multithreading:** `MoveTimer` class introduces delays for computer moves.
- **JDBC Demo:** Loads a mock driver and executes a sample SQL query.
- **Garbage Collection:** Method to request JVM cleanup with explanation of memory management.

## 🛠️ Technologies
- Java SE
- Collections Framework
- File I/O & Serialization
- Multithreading
- JDBC (mock demonstration)
